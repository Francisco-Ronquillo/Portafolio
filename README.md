**Descripción**
El sitio presenta la información profesional, formación, habilidades técnicas y proyectos del desarrollador mediante una interfaz responsive.
El proyecto utiliza una estética inspirada en Hades: fondos oscuros, acentos dorados y rojos, bordes luminosos, tipografía de inspiración clásica y componentes interactivos.
Este proyecto utiliza una inspiración visual basada en el videojuego Hades. 

**Incluye:**

-Tarjeta de perfil interactiva con efecto de giro.

-Sección de perfil profesional y formación.

-Lista visual de tecnologías y niveles de aprendizaje.

-Galería modal para consultar las capturas de cada proyecto.

-Contador de imágenes, indicadores y navegación con flechas.

-Navegación con teclado dentro de la galería.

-Sistema de diseño documentado dentro de la página.

-Formulario de contacto con validación en el navegador.

-Limpieza automática de los campos después de un formulario válido.

-Diseño responsive para escritorio, tabletas y dispositivos móviles.

**Tecnologías utilizadas**

-HTML5
-CSS3	
-JavaScript	
-Devicon	
-Google Fonts	

**Visualización local**

**Opción 1: abrir directamente**
 -Descarga o clona el proyecto.

 -Verifica que index.html, las carpetas css, js y sources mantengan sus rutas.

 -Abre index.html con un navegador moderno.
Esta opción permite revisar la mayor parte del diseño, la tarjeta volteable y la interfaz general.

**Opción 2: servidor local recomendado**
Usar un servidor local evita problemas con rutas, imágenes y comportamiento del elemento <dialog>.
Con Visual Studio Code:

-Instala la extensión Live Server.

-Abre la carpeta del proyecto.

-Haz clic derecho sobre index.html.

-Selecciona Open with Live Server.
